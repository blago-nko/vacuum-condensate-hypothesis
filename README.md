# Гипотеза вакуумного конденсата Вселенной
**(The Vacuum Condensate Hypothesis of the Universe)**

> **Статус:** Открытая исследовательская программа / Preprint Draft  
> **Лицензия:** Text: CC BY 4.0 | Code: MIT  

## О проекте
Этот репозиторий содержит исходники, математические выкладки и численные модели для работы «Гипотеза вакуумного конденсата Вселенной». 

Цель — объединить проблемы тёмной материи, тёмной энергии, барионной асимметрии и природы массы через единую термодинамическую модель четырёхканального фазового перехода.

🔗 **[Читать полную статью](docs/main_paper.pdf)**  
💻 **[Смотреть код расчетов](scripts/)**  
📊 **[Интерактивные графики](src/pages/plots/)**

## Структура
- `src/`: Исходники Astro (страницы, компоненты, контент).
- `scripts/`: Python-скрипты для научных расчетов.
- `docs/`: Текстовые версии статей, PDF, LaTeX-исходники.
- `public/`: Статические ассеты (данные, изображения).
